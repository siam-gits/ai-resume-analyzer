# AI Resume Analyzer

AI Resume Analyzer is a smart recruitment tool that matches resumes to job listings using AI-powered analysis. It offers a seamless hiring workflow with job management, resume uploads, and suitability scoring.

## 🚀 Live Demo
https://puter.com/app/ai-resume-analyzer-siam

## 📂 Source Code
https://github.com/siam-gits/ai-resume-analyzer

## ✨ Features
- AI-based resume-to-job matching  
- Resume uploading and parsing  
- Job post creation and management  
- Candidate ranking  
- Fully integrated with Puter.js for data storage  
- Clean React UI with smooth routing  

## 🛠️ Tech Stack
- React  
- TypeScript  
- Tailwind CSS  
- Puter.js
